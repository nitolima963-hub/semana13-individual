## Missão 1 – Teoria

### Tabela de conceitos

| Conceito | O que é (em uma frase) |
|---|---|
| DevOps | Forma de trabalho que une desenvolvimento e operações para entregar sistemas com mais qualidade e rapidez. |
| Integração Contínua (CI) | Prática de integrar o código frequentemente e executar testes automáticos a cada alteração enviada. |
| Entrega/Implantação Contínua (CD) | Na entrega contínua, o sistema fica pronto para publicar; na implantação contínua, a publicação acontece automaticamente. |
| Pipeline | Sequência de tarefas automáticas, como instalar dependências, executar testes e verificar erros. |
| Workflow | Arquivo que define como e quando uma automação será executada no GitHub Actions. |
| Job e Step | Job é um conjunto de tarefas executadas em uma máquina, e step é cada etapa dessas tarefas. |
| Runner | Máquina que executa os testes e comandos configurados no GitHub Actions. |
| Gatilho (trigger) | Evento que inicia uma automação, como um push no GitHub. |
| Modo headless | Forma de executar testes com navegador sem abrir uma janela gráfica. |
| YAML | Formato de arquivo utilizado para configurar o GitHub Actions, organizado por espaços e indentação. |
