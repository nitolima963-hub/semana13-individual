## Tabela de conceitos

| Conceito | Explicação simples |
|---|---|
| Integração Contínua (CI) | Testar automaticamente as alterações sempre que o código é enviado ao repositório. |
| DevOps | Forma de trabalho que aproxima desenvolvimento e operações para entregar software com qualidade. |
| QA | Área responsável por ajudar a garantir a qualidade do sistema, planejando e automatizando testes. |
| Shift-left | Começar a testar mais cedo, desde o desenvolvimento, e não apenas no final. |
| Entrega Contínua | Manter uma versão testada e pronta para ser publicada manualmente. |
| Implantação Contínua | Publicar automaticamente as mudanças aprovadas pelos testes. |
| Headless | Executar um navegador sem abrir a interface na tela. |
| GitHub Actions | Ferramenta do GitHub para automatizar tarefas, como executar testes a cada push. |
| Workflow | Arquivo YAML que descreve o processo de automação. |
| Runner | Máquina usada para executar os passos do workflow. |
| Job | Grupo de etapas que o runner executa. |
| Step | Uma etapa de um job, como instalar Node.js ou rodar testes. |
| Newman | Programa que executa coleções Postman pelo terminal. |

## Exemplos de respostas para as perguntas da missão

**Atenção:** o enunciado não trouxe as 3 perguntas do *roteiro do aluno*. As perguntas abaixo são apenas exemplos de estudo. **Substitua pelas perguntas oficiais do roteiro antes de entregar.**

**1. Por que a integração contínua é importante?**  
Porque o projeto é testado automaticamente a cada alteração enviada. Assim, a equipe descobre erros mais rápido e evita acumular problemas.

**2. Qual é a diferença entre CI, entrega contínua e implantação contínua?**  
CI integra e testa o código. Na entrega contínua, o código aprovado fica pronto para publicar, mas alguém autoriza. Na implantação contínua, ele é publicado automaticamente.

**3. O que o QA faz dentro do pipeline?**  
O QA organiza os testes e define quais falhas devem impedir que uma mudança siga para a entrega. Também acompanha os resultados para descobrir problemas.
